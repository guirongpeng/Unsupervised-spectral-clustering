# MGAGC

Official source: <https://github.com/awaw-Liyely/2026-IPM-MGAGC>.

Paper: Ye Li, Lei Yang, Binbin Sang, Guoyin Wang, *Multi-granularity
Granular-ball Anchor Graph Clustering with Self-Weighting*, Information
Processing & Management (2026), DOI: <https://doi.org/10.1016/j.ipm.2026.105037>.

The publisher currently provides no openly downloadable PDF. The complete
official source archive is retained under `official_source/`; `algorithm.py`
adapts its single `MGAGC.ipynb` entry point to the benchmark interface.
